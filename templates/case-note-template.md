# Case Note Template

Copy this block into the ticket. Keep it factual and short. No opinions, no unnecessary PHI.

```
CONTACT:     [Provider office / Member / Internal]  via [Phone / Portal / Email]
VERIFIED:    [NPI + TIN] or [Member ID + Name + DOB]
CLAIM:       [Claim #]  DOS: [MM/DD/YY]  CPT/Rev: [codes]
INQUIRY:     [What they asked, one line]
FINDINGS:    [Status, CARC/RARC, amounts, auth/eligibility/COB facts]
ROOT CAUSE:  [Provider error / Payer error / Correct adjudication / Member issue]
ACTION:      [Explained / Adjusted / Reprocess requested / Escalated to ___ ref ___]
NEXT STEP:   [Who does what, by when]
FOLLOW-UP:   [Date or N/A]
```

## Example (fictional)

```
CONTACT:     Provider office via Phone
VERIFIED:    NPI 1234567890 + TIN XX-XXX0000
CLAIM:       CLM-0000001  DOS: 03/04/26  CPT: 99214
INQUIRY:     Why claim denied as duplicate
FINDINGS:    CARC 18. Original CLM-0000000 same DOS/CPT pended for records since 03/10
ROOT CAUSE:  Provider resubmitted a pended claim
ACTION:      Explained; gave portal route for records
NEXT STEP:   Provider sends records for original claim by 04/09
FOLLOW-UP:   04/10
```
