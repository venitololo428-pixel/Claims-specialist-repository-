# Claims & Benefits Glossary

Quick reference of the terms used across this portfolio.

| Term | Meaning |
|---|---|
| **Adjudication** | The payer's process of reviewing a claim and deciding to pay, deny or adjust it |
| **Allowed amount** | Maximum the payer recognizes for a service under the plan or contract |
| **Appeal** | Formal request to reconsider a claim decision, with supporting documentation |
| **Authorization (prior auth / precert)** | Payer approval required before certain services |
| **Balance billing** | Billing the patient for the difference between billed and allowed. Not allowed for in-network providers |
| **CARC** | Claim Adjustment Reason Code: why a line was paid differently from billed |
| **Clearinghouse** | Intermediary that checks and forwards electronic claims (837) to payers |
| **CMS-1500 / 837P** | Professional claim form / electronic format |
| **COB** | Coordination of Benefits: rules deciding which plan pays first when there is more than one |
| **Coinsurance** | Percentage of the allowed amount the member pays after the deductible |
| **Copay** | Fixed amount the member pays for a service |
| **Corrected claim** | Replacement of a claim that had an error (frequency code 7); void = code 8 |
| **CPT** | Current Procedural Terminology: codes for procedures and services |
| **Credentialing** | Process of verifying a provider and adding them to the payer's network |
| **Deductible** | Amount the member pays each plan year before the plan starts paying |
| **DOS** | Date of service |
| **EOB** | Explanation of Benefits: statement of how a claim was processed |
| **ERA / 835** | Electronic Remittance Advice: electronic version of the remittance used for posting |
| **HCPCS** | Codes for supplies, equipment, drugs and services not in CPT |
| **ICD-10-CM** | Diagnosis codes |
| **In-network / out-of-network** | Whether a provider has a contract with the payer |
| **Medical necessity** | Whether a service is appropriate and needed for the diagnosis under payer policy |
| **Modifier** | Two-character code that changes how a CPT/HCPCS code is read (e.g. 25, 59, LT, RT) |
| **NCCI edits** | National Correct Coding Initiative: rules for codes that cannot be billed together |
| **NPI** | National Provider Identifier: 10-digit unique provider ID |
| **Out-of-pocket maximum** | Most a member pays in a plan year; the plan pays 100% after it |
| **PHI** | Protected Health Information (see [HIPAA](../hipaa-compliance)) |
| **POS** | Place of service code (office, hospital outpatient, telehealth…) |
| **RARC** | Remittance Advice Remark Code: extra detail that accompanies a CARC |
| **Rejection** | Claim refused before adjudication (format or data errors); fix and resubmit |
| **Reprocessing** | Payer re-adjudicates a claim to correct a processing error |
| **Revenue code** | Code on institutional claims (UB-04) identifying the department or type of service |
| **SLA** | Service Level Agreement: target time to resolve a ticket or inquiry |
| **TIN** | Tax Identification Number of the provider's business |
| **Timely filing** | Payer's deadline to submit a claim after the date of service |
| **UB-04 / 837I** | Institutional claim form / electronic format |
| **Annual Enrollment** | Yearly window to elect or change benefits |
| **Defined contribution (401(k))** | Retirement plan where the benefit depends on contributions and investment returns |
| **QLE** | Qualifying Life Event: allows benefit changes outside Annual Enrollment |
| **Vesting** | Schedule that gives the employee ownership of employer contributions over time |
